# Aperendendo a como colocar o site responsivo
    Para a responsividade CSS, vamos definir uma classe que só será carregada quando a
    largura de tela do dispositivo for de 900 pixels ou menos. Com ela, vamos alterar a largura da classe ".menu" apara 100% do tamanho da tela do navegador.
    Normalmente, não é preciso mudar todas as propriedades da classe CSS.
